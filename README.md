# React Native Clothing Shop App

## 📌 Overview
This project is a mobile application developed using **React Native**.  
It represents a clothing shop where users can browse products, view details, add items to cart, and complete a purchase.

The application demonstrates component-based architecture, navigation handling, and modern UI design.

---

## 🚀 Features
- Browse clothing categories (Pants, T-Shirts, Shoes, Hoodies, Coats, Watches)
- View detailed product information (name, price, description, sizes)
- Add products to shopping cart
- Apply coupon functionality
- Full checkout and payment flow
- Clean UI with multiple screens

---

## 🛠 Technologies
- React Native
- JavaScript
- React Navigation
- Expo (if used)
